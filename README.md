# TOTHEWORLD
A web application for uploading and collaborating on creative content,
aimed to encourage people to show their unique ideas and to shine a light on their talents.

## Features
- Authentication and Roles: Secure JWT authentication with User and Admin access control.
- Multi-Format Media: File uploads with the help of Multer & Cloudinary 
- Dynamic Contest Platform: Active challenge feed, voter tracking and sorted leaderboard.
- Remix of posts: Tracking the parent-to-child tree when creators build upon existing works.
- Social Graph: Follow/Unfollow creators, personalized Following feed and view users profile galleries.
- Community Interaction: Comment threads and notifications.
- Admin Dashboard: Tools to manage users, delete inappropriate content and to host contests.


## Tech Stack

**Frontend:**
- React (Vite)
- MUI
- Axios and Rect Router
  
**Backend**
  - Node.js & Express.js
  - MongoDB
  - Cloudinary
  - JWT
